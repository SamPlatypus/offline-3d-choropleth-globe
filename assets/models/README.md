# Globe Model (Offline)

Place the mobile model here so the app can run fully offline:

**File required:**
```
atlas_hex_subdiv_5L.glb
```

**Download (≈ 1.1 MB):**
```
https://cdn.jsdelivr.net/npm/@aeryflux/globe@1.8.0/models/atlas_hex_subdiv_5L.glb
```

After downloading, the path should be:
```
assets/models/atlas_hex_subdiv_5L.glb
```

Then the `require('./assets/models/atlas_hex_subdiv_5L.glb')` in `App.tsx` will work and no network is needed at runtime.
